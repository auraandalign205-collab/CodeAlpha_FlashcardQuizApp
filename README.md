# CodeAlpha Internship - Flashcard Quiz App (Task 1)

A production-ready, interactive **Flashcard Quiz App** built with clean HTML5, CSS3 transitions, and raw vanilla JavaScript. This application was engineered as part of the CodeAlpha App Development Internship program to demonstrate core front-end software development paradigms, state lifecycle management, and full interactive UI elements.

## 🚀 Key Features Implemented
* **Interactive 3D Flip Mechanics:** Smooth CSS card rotation transitions separating the question front-face from the answer back-face upon interactive user evaluation requests.
* **State Operations Workflow (CRUD):** Complete custom management capabilities allowing users to add custom cards dynamically, edit existing layout properties, or delete active nodes seamlessly.
* **Dynamic Index Step Filtering:** Safe bounded array step algorithms enabling horizontal translation controls ("Next" and "Previous") coupled with conditional button visibility states.
* **Responsive Workspace Design:** Styled explicitly via strict CSS root parameters making the application adaptive for standard handheld mobile displays up to high-resolution desktop viewports.
